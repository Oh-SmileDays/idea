## 1. 메인 대시보드 레이아웃 (Markdown)

### 붙여넣기 전 확인
- 노션은 마크다운 붙여넣기로 **제목·구분선·인용·목록·할 일**은 자동 변환하지만 **열(Column)·임베드·버튼·링크된 DB 뷰는 생성하지 못함**.
- 아래 코드는 뼈대(섹션 제목 + 자리표시)를 만든다. 각 `` `자리표시` `` 줄을 4장 매뉴얼대로 실제 블록으로 교체하고, 섹션을 열로 드래그한다.

```markdown

---

### ⏰ 시계
`[상단-1열] /임베드 → Indify Flip Clock URL`

### 🌤️ 주간 날씨
`[상단-2열] /임베드 → Indify Weather URL (Seoul, 5일 예보)`

### 📝 마인드셋
> 걱정하지 마, 잘하고 있어.

**🧭 빠른 이동**
- 🎯 목표 관리
- 📁 프로젝트 매니저
- ✅ 작업 관리

---

`[중단-1열] /버튼 → ＋ 새 작업`
`[중단-1열] /버튼 → ＋ 새 노트`
`[중단-1열] /버튼 → ＋ 새 프로젝트`
`[중단-1열] /버튼 → ＋ 오늘 습관 기록`

### ✅ 오늘 할 일
`[중단-2열] /링크된 데이터베이스 보기 → 작업 관리 (필터: 마감일=오늘, 상태≠Done)`

`[중단-3열] /링크된 데이터베이스 보기 → 목표 관리 (필터: 최우선=체크, 상태≠Done)`

`[하단] /링크된 데이터베이스 보기 → 노트 (탭: 모든 노트 / 검토할 노트 / 즐겨찾는 노트)`
```

## 2. 핵심 데이터베이스 구조 및 CSV

### 관계도

```
핵심 영역 ──< 목표 관리 ──< 프로젝트 매니저 ──< 작업 관리
노트북 ──< 노트
일일 습관 (독립)
```
`──<` = 1:N 관계형(양방향). 영역·목표·프로젝트·작업·노트북·노트·습관 = DB 7개 (항목 1은 영역+목표, 항목 5는 노트북+노트).

### CSV 공통 규칙
- 첫 번째 열 → 제목(Title) 속성이 됨.
- 가져오면 대부분 **텍스트**로 생성됨 → 표의 "유형"대로 직접 변환.
- `Yes/No` 열 → 체크박스로 변환하면 Yes=체크.
- `xxx_연결용` 열 → 관계형 연결 시 참고용. 관계 연결 후 삭제.
- 관계형·수식·버튼 속성은 CSV로 만들 수 없음 → 가져온 뒤 추가 (4장 STEP 4~5).

| 설명 | 텍스트 | |
| 목표 | 관계형 | 목표 관리 DB에서 생성 시 자동 생성(양방향) |

## 3. 노션 수식 (Formula 2.0)

### 공통: 진행률 바 표시 설정 (이미지와 동일한 파란 막대 + 71.4%)
수식 속성 편집 화면에서:
1. `숫자 형식 (Number format)` → **백분율 (Percent)**
2. `소수 자릿수 (Decimal places)` → 습관/프로젝트 `1`, 목표 `2` (이미지의 66.67%)
3. `표시 형식 (Show as)` → **막대 (Bar)**, `색상` → 파랑, `숫자 표시 (Show number)` ON

수식은 0~1 사이 숫자를 반환한다. 표시 형식에서 막대·퍼센트로 렌더링된다.

### F-1. 습관 달성률 — DB: 일일 습관 / 속성명: `달성률`
```
lets(
  checks, [
    prop("Make your bed"),
    prop("Drink water"),
    prop("Review today's tasks"),
    prop("Focus for 25 minutes"),
    prop("Move your body"),
    prop("Read 10 pages"),
    prop("Night journal")
  ],
  round(checks.filter(current).length() / checks.length() * 1000) / 1000
)
```
- 습관 추가/삭제 시 `[ ]` 목록에 `prop("새 습관")`만 추가/삭제. 분모는 자동 계산.

### F-2. 프로젝트 진행률 — DB: 프로젝트 매니저 / 속성명: `진행률`
```
lets(
  total, prop("작업").length(),
  done, prop("작업").filter(current.prop("상태") == "Done").length(),
  if(total == 0, 0, round(done / total * 1000) / 1000)
)
```

### F-3. 텍스트 막대 (선택) — 어느 DB든 / 속성명: `진행 바`
숫자 막대 대신 `▰▰▰▱▱▱▱▱▱▱ 25.0%` 형태가 필요할 때. `pct` 줄만 DB에 맞게 교체.
```
lets(
  pct, if(prop("작업").length() == 0, 0,
    prop("작업").filter(current.prop("상태") == "Done").length() / prop("작업").length()),
  n, round(pct * 10),
  repeat("▰", n) + repeat("▱", 10 - n) + " " + format(round(pct * 1000) / 10) + "%"
)
```
- 습관 DB용 `pct`: `prop("달성률")`

### F-4. 목표 진행률 (하위 프로젝트의 모든 작업 기준) — DB: 목표 관리 / 속성명: `진행률`
```
lets(
  tasks, prop("프로젝트").map(current.prop("작업")).flat(),
  total, tasks.length(),
  done, tasks.filter(current.prop("상태") == "Done").length(),
  if(total == 0, 0, round(done / total * 10000) / 10000)
)
```

### F-5. 목표 남은 단계 (미완료 프로젝트 수) — DB: 목표 관리 / 속성명: `남은 단계`
```
lets(
  left, prop("프로젝트").filter(current.prop("상태") != "Done").length(),
  format(left) + if(left == 1, " Step", " Steps") + " Remaining"
)
```

### F-6. 진행 중 목표 수 — DB: 핵심 영역 / 속성명: `진행 중 목표`
```
"진행 중 목표 " + format(prop("목표").filter(current.prop("상태") == "In progress").length()) + "개"
```

### F-7. 작업 기한 표시 — DB: 작업 관리 / 속성명: `기한`
```
if(empty(prop("마감일")), "",
  if(prop("상태") == "Done", "✅ 완료",
    lets(
      d, dateBetween(prop("마감일"), today(), "days"),
      if(d < 0, "⏰ 기한 초과 " + format(abs(d)) + "일",
        if(d == 0, "🔥 오늘", "D-" + format(d)))
    )
  )
)
```

### F-8. 노트 수 — DB: 노트북 / 속성명: `노트 수`
```
format(prop("노트").length()) + " Notes"
```

### 수식 오류 체크리스트
- `prop("이름")`의 이름이 속성명과 **공백·대소문자까지** 일치해야 함.
- 관계형 이름(`작업`, `프로젝트`, `목표`, `노트`)이 2장 표와 다르면 수식 내 이름도 변경.
- 상태 옵션값은 정확히 `Done` (대소문자 구분).

## 4. 클릭 위치 기준 구축 매뉴얼

### STEP 0. 환경 설정 (1분)
1. 좌측 사이드바 상단 [설정 (Settings)] 클릭 → [내 설정 (Preferences)] → [테마 (Appearance)] → **다크 (Dark)**.

### STEP 1. 대시보드 페이지 생성 (3분)
1. 좌측 사이드바 [비공개 (Private)] 섹션 이름에 마우스 오버 → 오른쪽 [＋] 클릭 → 새 페이지.
2. 제목 입력: `올인원 생산성 관리 시스템`.
3. 제목 위에 마우스 오버 → [아이콘 추가 (Add icon)] → 🌿 검색 후 선택.
4. 제목 위 [커버 추가 (Add cover)] → 커버 우측 하단 [커버 변경 (Change cover)] → [업로드 (Upload)] → 픽셀아트 GIF/이미지 업로드 → [위치 변경 (Reposition)]으로 높이 조절 → [위치 저장].
5. 화면 **우측 상단 [•••]** 클릭 → **[전체 너비 (Full width)]** 토글 ON. (필요 시 [작은 텍스트 (Small text)]도 ON)

### STEP 2. DB 보관 페이지 생성 + CSV 7개 가져오기 (5분)
1. 대시보드 본문 맨 아래에서 `/페이지` 입력 → [페이지 (Page)] → 제목 `📦 시스템 DB`.
2. `📦 시스템 DB` 페이지 안으로 이동.
3. 파일 탐색기에서 `csv/` 폴더의 CSV 7개를 선택 → 노션 페이지 본문으로 **드래그 앤 드롭** → 나오는 팝업에서 [데이터베이스로 가져오기 (Import as database)]  
   - 대안: 화면 **우측 상단 [•••]** → [가져오기 (Import)] → [CSV] → 파일 선택 (1개씩).
4. 생성된 DB 7개 확인: 핵심 영역 / 목표 관리 / 프로젝트 매니저 / 작업 관리 / 일일 습관 / 노트북 / 노트.
5. 각 DB를 열고 제목 왼쪽 아이콘 자리 [아이콘 추가] → 🧭 🎯 📁 ✅ 🔁 📚 📒 지정.

### STEP 3. 속성 유형 변환 (DB별 2~3분)
공통 조작: 표의 **열 머리글(속성 이름) 클릭** → [속성 편집 (Edit property)] → [유형 (Type)] → 원하는 유형 선택.

| DB | 변환 |
|---|---|
| 목표 관리 | 상태→선택, 최우선→체크박스, 목표일→날짜 |
| 프로젝트 매니저 | 상태·우선순위→선택, 시작일·종료일→날짜 |
| 작업 관리 | 우선순위·상태→선택, 마감일→날짜 |

### STEP 4. 관계형 연결 (10분)

1. `작업 관리` DB 표의 **맨 오른쪽 열 머리글 [＋]** 클릭.
2. 유형 목록에서 [관계형 (Relation)] 선택 → 대상 DB 검색창에 `프로젝트 매니저` 선택.
3. [프로젝트 매니저에 표시 (Show on 프로젝트 매니저)] 토글 **ON** → 상대 속성 이름 `작업` 입력.
4. 속성 이름을 `프로젝트`로 지정 → [관계 추가 (Add relation)].
5. 각 행의 `프로젝트` 셀 클릭 → 검색창에 `프로젝트_연결용` 열의 값 입력 → 항목 클릭.

6. 연결이 끝나면 `프로젝트_연결용` 열 머리글 클릭 → [속성 삭제 (Delete property)].

|---|---|---|---|---|---|

| ④ | 노트 | 노트북 | 노트북 | 노트 | 노트북_연결용 |

### STEP 5. 수식·버튼 속성 추가 (10분)
**수식**

| DB | 속성명 | 코드 |
|---|---|---|

   권장 비율: 상단 25 : 40 : 35 / 중단 22 : 45 : 33.
6. 4열 원할 때(이미지처럼 우측 끝 내비게이션 분리): `🧭 빠른 이동` 묶음을 3열 **오른쪽 끝** 세로 파란 선에 드롭.

### STEP 10. 빠른 추가 버튼 (10분)
1. 중단-1열 자리표시 줄 클릭 → `/버튼` (`/button`) → [버튼 (Button)].
2. 버튼 이름 `＋ 새 작업`, 아이콘 ➕.
3. [＋ 새 작업 추가 (Add action)] → [페이지 추가 위치 (Add page to)] → `작업 관리` 선택.
4. 같은 설정창에서 [＋ 속성 편집]: `마감일` = [오늘 (Today)], `상태` = Not started.
5. [＋ 새 작업 추가] → [페이지 열기 (Open page)] → 방금 추가한 페이지 → [측면 보기 (Side peek)].
6. 우측 하단 [완료 (Done)].
7. 나머지 3개 반복:

| 버튼 | 추가 위치 | 기본 속성 |
|---|---|---|
| ＋ 새 노트 | 노트 | 작성일=오늘 |
| ＋ 새 프로젝트 | 프로젝트 매니저 | 상태=Not started, 시작일=오늘 |
| ＋ 오늘 습관 기록 | 일일 습관 | 날짜=오늘 (반복 템플릿 사용 시 생략 가능) |

### STEP 11. 마무리 (5분)
1. 마크다운 자리표시 줄(`` `[...]` ``)이 모두 실제 블록으로 바뀌었는지 확인 후 남은 줄 삭제.
2. 좌측 사이드바에서 `올인원 생산성 관리 시스템` 오른쪽 [•••] → [즐겨찾기에 추가 (Add to Favorites)].
3. 샘플 데이터 정리: 각 원본 DB에서 행 왼쪽 [⋮⋮] 선택(여러 행은 체크박스) → [삭제 (Delete)].  
   샘플을 남길 경우 작업 `마감일`을 오늘 날짜로 바꿔 "오늘 할 일" 뷰 동작 확인.
4. 모바일 앱에서 확인: 열은 세로로 쌓임. 모바일 순서가 중요하면 중단 섹션 열 순서를 `오늘 할 일`이 첫 열이 되도록 조정.
